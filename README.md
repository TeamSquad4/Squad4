# Squad4

WitchHunt Hackathon Prototype Development - HealthChain

This project presents a secure and intelligent Medical Record Management System designed to help patients and healthcare providers manage medical data efficiently. The platform allows patients to store and organize their medical documents such as lab reports, prescriptions, and scan results in a centralized digital system. Doctors can securely access these records with patient permission, enabling faster and more informed medical decisions. The system integrates Artificial Intelligence to classify medical documents, summarize patient history, and detect anomalies in health data. Additionally, modern security techniques are implemented to ensure patient privacy and data integrity. This solution aims to reduce repeated diagnostic tests, improve communication between hospitals, and provide quicker access to critical medical information.
